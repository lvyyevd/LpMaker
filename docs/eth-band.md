# Robinhood 单区间净敞口策略（200U）

显式配置 `strategy.eth_persistent.band` 才启用，代码位于 `src/strategy/eth/band.rs`。
旧长持配置缺少该字段时保持原行为；Base、Solana 不启用这个配置。

## Linux 一键切换

先将本次代码同步到服务器，再执行：

```sh
cd ~/jy/LpMaker && bash scripts/switch-robinhood-band.sh
```

整个编译、停旧进程、平仓、迁移和启动任务均在独立后台会话运行。入口返回任务PID和独立进度日志；Ctrl+C或SSH断开不会终止它。`run.log` 是最终策略运行日志，平仓未完成前看入口打印的进度日志。不要重复提交切换任务。

流程复用事务化迁移：
1. 编译和本地只读预检；失败不停止原运行进程。
2. 只停止当前项目、`config/local.toml` 对应的实盘进程，等待状态锁释放。
3. 使用旧记录保存的配置对账，撤销 Hyperliquid ETH 挂单，移除本 Robinhood 池全部LP并领取手续费，将钱包WETH兑换为USDG，平掉ETH合约。
4. 两次实际观察确认空仓（仅保留已经验证不可交易的基础币极小尾差）。
5. 完整备份旧配置与状态，再清空活动记录/缓存，原子安装新策略配置。原生Gas、`.env`、锁文件、其他策略和旧备份保留。
6. 独立后台启动新策略；日志追加到新 `run.log`，旧日志归档。等待完成首轮策略决策后才报告健康。首仓仍需实时风控、报价和资金条件通过。

遇到未知交易、部分成交、非ETH合约/其他策略挂单、配置绑定冲突或RPC故障会停止后续清理。旧台账保留，修复后重跑同一命令；不得通过删除pending文件跳过。
这条命令会真正平仓、重置净值观察基准，不用于普通日常重启。

只读预览（不加载签名密钥、不发交易）：

```sh
./target/release/lp-maker --config config/local.toml switch-robinhood-band
```

保留仓位和记录再次后台启动，使用 `bash scripts/start-background.sh`。

## 策略参数

- 200U预算：120U LP、60U Hyperliquid保证金、20U储备。跨平台不自动划转或充值；专用Hyperliquid全仓账户，最高3倍，目标计算预留余量为2.55倍。
- 单区间：24小时已完成收益为正时，下沿−7.825%、上沿+8%；否则交换两边宽度。相对建仓报价，tick向内取整；不用旧的几何区间。建仓报价与最终链上成交价可能有差异，滑点检查保留。
- 净ETH敞口=实际LP/钱包ETH市值−实际空单名义价值。目标允许区间−60U～+47.24U，超出后调整至最近边界。首次建仓后核对目标；常态每120分钟检查，调整差額≥15U才下单。未成交目标持久化，后续根据实际库存重算。
- 常态优先Maker；建仓/重设后的目标核对和风险退出允许Maker短等候后IOC。最小订单额、精度、可用保证金仍由执行器核对。目标区间不是任何瞬间的硬敞口上限。
- 普通出界：连续16次15分钟同侧观察、持仓至少48小时后重设。移除旧LP后保留实际库存和已有空单，等待60秒，重新检查市场再建仓。风险退出不受48小时限制。
- 风险退出：1小时/相对最新小时收盘价跌幅>3.5%，24小时跌幅>9%，72小时跌幅>16%，6根小时对数收益标准差>1.6%；同时保留基差和报价时效检查。
- 本次持仓的组合风控净值从局部峰值回撤2%暂停；全局暂停阈值=max(3%,本次入场时的历史回撤+0.5%)，最高4.75%。
- 风险暂停后冷却3小时，连续观察4个健康完成小时后恢复：6小时回报≥−1%、1小时回报≥−0.5%、波动率<1.28%、所有危险条件解除。断线不补算历史健康小时。首仓豁免等待但不豁免风险条件。
- **观测到全局回撤达到5%仍进入持久化Halted**。自动恢复只适用于前面的风险暂停；重启不能清除硬停机或历史峰值。5%是动作触发阈值，不保证滑点/跳空后损失≤5%。

## 净值口径与回测差异

新策略风控净值=200U+全账户观测净值−首次可信观测净值。额外闲置稳定币不再把5%的亏损额度扩大。首次基准、持仓时钟、全局峰值和未成交目标均写入检查点，重新入场不会清零。
这个净值仍沿用现有账户观测，不校正入出金、未扣原生Gas，不是完整净利润；策略运行中不要通过充值/提现改变风控基准。日志单独打印新策略风控净值与净ETH敞口。

候选在184天历史、假设APR40%、基础执行成本下净收益5.589%，LP持有94.80%，回撤保守上界4.704%。**成本压力未通过，绝非已经满足半年10%目标。** 研究数据已经参与选参，不是独立样本外。实盘不伪造40%手续费；Maker成交等待、确认延迟、断线、Gas和池子真实费用都会造成差异。

离线完整诊断在违反5%约束后继续跑是为了暴露问题；实盘硬停机不会允许这个诊断行为继续亏损。正常区间切换若崩溃，沿用已持久化workflow对账并退出，不盲目重发mint。在线风险基准按200U归一化，不能把新的上线版本结果直接声称为再次验证了5.589%。

本地测试使用回环RPC、公开固定签名测试向量和脚本替身，未连接实盘账户或发送真实交易。
