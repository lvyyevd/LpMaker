# ETH 长持 LP（5%回撤退出阈值）

这是显式选择的新策略，代码在 `src/strategy/eth`；适配 EVM Uniswap v3 与 Hyperliquid。原 Robinhood/Base 配置不含 `strategy.eth_persistent` 时继续使用原策略，Solana 入口不变。

## 启动模拟观察

在项目根目录运行：

```sh
cargo build --release --locked && ./target/release/lp-maker --config config/eth-persistent-dd5-paper.toml run
```

默认 paper，不签名、不发送交易。状态目录为 `data/eth-persistent-dd5-paper`，重启复用同一目录，不删除记录。已有链上仓位不能通过改状态目录自动转换；实盘必须使用下方显式迁移流程。

## 从旧 Robinhood 实盘切换

本次 `config/local.toml` 已选用新策略。代码同步到 Linux 服务器后，在项目根目录执行：

```sh
bash scripts/switch-robinhood-dd5.sh
```

脚本先编译及预检，成功后停止该项目、该配置的旧进程，等待状态锁释放。按 `config.json` 保存的**旧策略参数**核对并撤销 Hyperliquid ETH 挂单、移除本池全部 LP/领取费用、将钱包 WETH 换成 USDG、平掉 ETH 合约。连续两次实际观察确认退出后，旧记录完整备份到状态目录旁的 `live-200_reset_backup_*`，再清空活动记录并原子写入新配置。原生 ETH Gas、`.env`、其他配置及备份不删除。极小且不可交易的 WETH 尾差保留并记录。

服务器当前的 RPC、主账户、API 钱包环境变量名、状态路径保留不变；无论服务器配置仍为旧策略，还是已经同步了新参数，都能从保存的旧绑定恢复退出参数。账号、链或其他交易参数与原状态不匹配时停止，不能借迁移跨账户平仓。Hyperliquid 如有其他币种仓位/挂单会停止，不平掉 Solana 等其他策略。

**这是一次真实平仓和首次切换命令，不是日常重启命令。** 每次成功执行都会重新建立净值/持仓/APR观察基准，旧累计信息在备份中。未确认交易、部分成交、RPC失败或配置被并发修改时保留记录并停止后续步骤；修复原因后重新执行同一命令，不要手动删除状态。迁移标记会阻止未完成切换时直接启动策略。

成功后后台运行 `run --execute`，日志写入 `run.log`，旧日志移入 `data/operator-logs`。脚本等到至少完成一次策略决策才报告健康；进程启动不表示已经建仓。首仓免除冷却等待，但下跌/波动、数据、基差、资金等检查仍必须通过。

可单独只读预览，不加载签名密钥、不发送交易：

```sh
./target/release/lp-maker --config config/local.toml switch-robinhood-dd5
```

## 资金及规则

- 200U：120U LP、60U专用 Hyperliquid 全仓资金、20U储备。合约杠杆设置3倍，**不是200U开3倍LP，也不是初始3倍逐仓后不补保证金**。
- 单区间 `P/10～10P`（half_width=9，P为每次建仓价）；预算预留沿用既有执行器。初始ETH/报价币价值约各半。
- 目标空单为LP和钱包ETH总库存的50%。每小时更新目标，差额≥5U才请求交易；遵守最小下单额/精度。未成交目标持久化，后续继续核对；常态优先Maker，退出/跨平台调仓可紧急IOC。
- 暂停：小时跌幅>3.5%，24h跌幅>9%，72h跌幅>16%，或最近6个已完成小时对数收益标准差>1.6%。另保留行情时效、池价/合约价基差、保证金预检。
- 风险退出后冷却12小时，并满足至少2个连续观察的健康小时：1h回报≥−0.5%、6h回报≥−1%、6h波动率<1.28%、全部风险条件解除。首仓仅豁免等待，不豁免风险检查。
- 越界超过1%、连续8个15分钟观察后退出；至少等待15分钟及健康条件通过后再建。断线不补算健康小时，也不累计断线期间突破次数。
- 从账户峰值回撤达到5%进入Halted，保持峰值和停机状态；重启不能自动解除。5%是触发阈值，不是保证成交后最大亏损≤5%。

## 本次离线验证

2026-03-23至2026-09-23 UTC，184天，200U：

| 模型结果 | 旧5%候选 | 新候选 |
|---|---:|---:|
| 净收益 | 14.6079% | 15.1740% |
| 最大回撤（1分钟） | 4.1893% | 3.8594% |
| LP持有天数 | 180.3771 | 178.2069 |
| LP手续费（固定40% APR假设） | 24.0985U | 24.0307U |

新候选净利润30.3480U，持有和区间内赚费均96.8516%。基准使用taker4.5bps、现货/合约滑点各5bps、每次链上写入0.02U；10bps/Gas0.05U时收益13.2222%、回撤4.4255%。30bps/Gas0.10U时收益−1.5825%、回撤5.2747%，触发停机，持有率39.45%，不再符合80%要求。

研究选参使用过整段历史，非独立样本外。Binance ETHUSDT代理池价和合约价，Hyperliquid实际历史资金费。**未验证真实宽区间能获得40%APR**。实时paper不模拟LP手续费，因此不会显示假设的40%收入。研究按即时taker成交计费，实际Maker可能不成交；费用较保守不等于成交时序保守。

研究的20U按现金支付Gas，未模拟原生ETH储备价格。现有实盘净值仍未扣Gas/校正出入金，也不包含原生Gas币市值；实盘5%保护对应现有观测净值，不能描述成完整钱包净损失保证。专用全仓资金由整个对冲账户支持，旧3倍逐仓不等价。迁移工具不会跨链充值或把保证金账户自动限制为60U，账户多余资金也可能支持全仓风险；保持专用账户。开发验证仅使用离线测试，服务器实际切换由操作者执行上方命令。
