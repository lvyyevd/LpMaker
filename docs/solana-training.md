# SOL 半年 25% 目标研究

目标按**整个账户扣除模型成本后的净收益**计算：200 美元本金需要净赚 50 美元。LP 手续费固定假设为 40% 单利 APR，对冲保持 3 倍，回撤限制沿用 5%。达到一个历史样本中的目标，不代表未来能够达到；训练不会覆盖实盘配置或自动下单。

## 研究边界

Rust 实现位于 `src/solana/research/training.rs`，命令是独立的 `lp-maker-solana train`。只读取已有本地行情，输出位于 Git 忽略的 `backtests/solana/`。不调用 Solana、EVM 或 Hyperliquid 交易接口。原 Robinhood/Base 策略、检查点和重启逻辑保持原样。

价格窗口固定为 2026-03-18 08:00 UTC 至 2026-09-18 08:00 UTC，共 184 天。前 92 天训练、接着 30 天参与验证与参数排名，最后 62 天仅用于复核排名胜出的参数。但这 62 天在此前研究中已看过，因此不能称为盲测。任何最终候选都还需要新时间段的前向模拟验证。

## 搜索及账户核算

- 搜索区间宽度、区间内对冲比例、EMA/动量/波动率门槛、健康小时、冷却时长、LP 预算和对冲死区。始终保留下降趋势、急跌、大波动退出及冷却机制。
- APR 只按实际在区间内的 LP 本金和时间计提；停仓、越界不产生假设手续费。终点撤出 LP、关闭对冲并计入成本。普通模型与双倍执行成本模型都参与开发期筛选。
- 原生 SOL 租金/gas 储备在每个独立回放开始时从同一笔资本购买，随后逐根行情按市价计入净值，并单列其币价损益及双向换币费用。它不算 LP 收益，也不算额外赠送本金。
- 租金使用已安装 Meteora SDK 的账户尺寸公式及假设的 Solana 免租金系数，另预留 0.05 SOL。它是研究预算，真实租金必须由目标 RPC 报价；新增 bin-array 的历史分布未知，不能声称模拟精确复现链上成本。
- 保证金容量随实际对冲账户权益下调。研究保守检查逐仓权益是否低于不利最高价对应名义价值的 10%；触发者不得入选。这是筛选缓冲，不是重建交易所历史强平引擎，小时最高价也不是历史标记价。
- 交易成本仍是假设：换币 34 bps、对冲 7.5 bps（含滑点）、每次 LP 操作 0.10 美元。未假定挂单必成交，也未用 maker 低费率美化结果。

若小时模型达到 25%，自动增加 5 分钟池价复核、不利低价路径、双倍费用及 30% APR 敏感性测试。缺失的早期 Hyperliquid 5 分钟价格使用当时小时开盘基差构造代理，明确标注为模型；一根缺失的池价不插值，缺口触发退出。

## 运行和恢复

本地已有六个月行情时，运行：

```bash
bash scripts/solana/train_target.sh
```

读取中文进度（不会操作账户）：

```bash
python3 scripts/solana/training_status.py backtests/solana/2026-09-19-target25
```

脚本冻结独立的二进制和 paper 配置；训练持续累计 10 小时，或在发现同时通过小时与细粒度筛选的目标候选时提前结束。相同命令会继续已有进度；数据、配置、种子或目标发生变化必须使用新目录。`--max-candidates` 仅用于短程测试，不能把短程结果称为已训练 10 小时。

输出内容：

- `progress.json`：当前阶段、累计时长、完成组数、最优候选及收益拆分。
- `trials.jsonl`：所有完成候选及开发期结果；逐条写入并同步磁盘。
- `best-paper.toml`：开发期排名最高的研究配置，即使尚未通过验证也会保存，不能视为可部署结论。
- `curves-*.json`、`fine-*.json`：候选曲线与细粒度复核。
- `assumptions.json`：模型口径与限制。

进度文件原子替换，训练目录独占锁防止重复进程。崩溃后的未提交尾部会重算；已提交日志损坏会停止并保留现场。检查点不涉及实盘仓位，没有删除线上状态的步骤。

即使未找到 25%，仍保留实际结果并明确报告目标未达成；不会调高 LP APR、放大合约杠杆、删除亏损月份或取消风险控制来达标。

## 训练结束后的独立复核

`examples/solana_training_review.rs` 核对冻结批次的源码/配置/数据绑定，检查全部已完成记录，并从满足最低 LP 在场时间的候选中按原开发期评分选出诊断候选。它复算四个开发期结果，再输出连续半年、最后 62 天、成本压力和 5 分钟敏感性结果。空仓时 SOL 储备产生的收益会单独列出，不会被当成 LP 收益。

```bash
cargo run --release --locked --example solana_training_review -- \
  --data backtests/solana/2026-09-18-six-month \
  --training backtests/solana/2026-09-19-target25 \
  --output backtests/solana/2026-09-19-target25/review

# 图表脚本需要在 Python 环境中安装 matplotlib。
python3 scripts/solana/render_training_review.py \
  --training backtests/solana/2026-09-19-target25
```

报告、图表、CSV、诊断参数和复核 JSON 均写入训练目录的 `review/`，保持本地且不进入 Git。诊断候选即使整段半年盈利，只要开发期检验未通过，仍不能当作合格上线策略。
