# WSS 观察复用与 RPC 请求优化

近 5 分钟池子成交量已停止计算和打印。`run`、`monitor` 不再启动成交量后台任务，也不再为它二分查询历史区块、调用 `eth_getLogs` 或访问历史节点。旧 `monitor_volume.json` 不再读取或写入；无需删除任何状态文件。

## 数据从哪里来

同一条已建立的 EVM WebSocket 订阅 `newHeads`、池子日志和 Position Manager 的 Transfer / IncreaseLiquidity / DecreaseLiquidity / Collect 事件。没有新增监听连接。

- 连续且新鲜的区块头用于选择原配置要求的确认块。首次、重连、缺块、重组后，以及每 60 秒，用 RPC 核对区块哈希和时间。校验不一致时丢弃锚点，进入读取恢复，不能继续用不一致的观察下单。
- Swap 推送直接提供中文报告中的实时参考价，并注明未确认。确认块上的 `slot0` 和 `liquidity` 仍由 RPC 获取；不能把没有成交误认为池子价格无效，也不能把未确认行情当作已确认库存。
- 我方 NFT 转移、增减流动性或领取费用事件使共享观察失效；同时保留至少每分钟一次的完整 NFT 枚举。枚举结果必须与登记清单一致才能复用，避免遗漏外部仓位。
- 已确认 LP 本金和待领取手续费继续读取真实的仓位和 fee growth；不从池子成交量推算个人收益。滚动 1 小时 APR 保留原算法和原采样时间。

## 消除重复请求

`liquidity/uniswap_v3/observations.rs` 按链、池、合约、代币与传输端点隔离共享观察。Robinhood 和 Base 可复用这套实现，Solana 模块不使用它。

| 查询 | 原行为 | 当前行为 |
| --- | --- | --- |
| 池子快照 | 每次 5 个 RPC | WSS 连续且已锚定时 2 个 RPC；初次 4 个，定期锚定另加 1 个 |
| 同确认块的 2 笔 NFT 本金与费用 | 每次 12 个 RPC，模块间重复 | 共 10 个 RPC；合并全局 fee growth，同块并发读取只发一组 |
| 普通 Hold | 为对冲判断及执行后检查再次读取完整组合 | 复用本轮已核对库存，不重复调用完整组合读取 |
| 监控仓位 | 每轮独立查全部 NFT 和费用 | 有匹配且不超过 15 秒的共享观察时复用，否则重新查询 |
| 成交量 | 历史区块定位、日志补数 | 0 个 RPC，已移除运行任务 |

表中数字是本机模拟节点测试的模块请求数，不是整台服务器的请求总量或降幅承诺。首次启动、重新对账、交易、断线、外部 NFT 变更仍需更多查询。WSS 不可用时池子快照回退到 RPC；已缓存不可变 `tickSpacing` 后通常为 4 次。

中文状态摘要新增“RPC 请求”统计：本报告周期实际发出数量、实际间隔秒数、该进程中此端点累计数量。包括策略、监控、nonce、广播的实际发送尝试；不把等待队列、缓存命中或 WSS 推送算作 RPC。第一次报告间隔可能不足 60 秒。不同端点和其他进程的请求不在此计数中。

## 新鲜度与重启

池子快照最多复用 2 秒；同确认块的合约结果最多保留 30 秒并限制容量。合约缓存键包含区块哈希；监控保留共享观察的原时间，不能用复用时间掩盖陈旧数据。断线、缺块、重组、相关 NFT 事件、本地交易广播与确认会使相应观察失效；失效前在途读取不能重新发布到新一代缓存。

交易前报价、钱包余额、nonce、模拟执行和交易回执继续核对。普通 Hold 仍检查观察时间，对冲控制器仍核对真实合约持仓、挂单和资金。未知交易结果、重启对账、冷却、下降趋势和波动率保护规则均保留。

缓存仅在内存中，不新增持久化交易状态，也不修改旧检查点、NFT 台账、订单、pending 和 nonce 的格式。旧 TOML 中的 `volume_window_seconds`、`volume_refresh_seconds`、`backfill_blocks` 仅为兼容保留，填写任何值都不会启动实时成交量任务。升级继续使用原配置及状态目录，重新编译后按保留状态的流程重启。

## 本地验证

`tests/evm_observations.rs` 覆盖请求数、并发复用、钱包及交易报价强制读取、WSS 中断/重组/过期/哈希不一致、NFT 变更失效、库存清单与有效期、缓存世代隔离，以及完整监控循环没有历史日志请求和成交量任务。真实环回 WebSocket 测试确认新订阅都使用同一连接，退出时使共享流状态失效。

Hyperliquid 的 Hold 回归使用会拒绝额外库存读取的模拟执行器，验证复用库存、过期拒绝和 LP 变更拒绝。原手续费、APR、成交、恢复和不同链回归继续执行。

所有测试只连接本机模拟服务，未加载实盘密钥或发送实盘交易。本地修改不会自动更新服务器，部署后的实际数量以新增请求日志为准。
